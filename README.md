# Portfolio – Caro Bibbo

Portfolio personal de Caro Bibbo, desarrolladora web. Ofrece landing pages, correcciones y mantenimiento de sitios web para negocios y profesionales.

Sitio en vivo: https://caro-bibbo-portfolio.vercel.app/

## Qué incluye

- **Servicios:** landing pages, correcciones, mantenimiento mensual y revisión express de sitios web.
- **Proyectos seleccionados:** trabajos para clientes (IDEB Balcarce, La Musa Incarnata) y proyectos académicos de frontend y backend.
- **Proyectos de práctica:** plegados en una sección desplegable para no restarle protagonismo a los trabajos reales.
- **Sobre mí, tecnologías y contacto** (WhatsApp con mensaje precargado y email).

## Tecnologías

- HTML5
- CSS3 (variables, grid, flexbox y diseño responsive)
- Font Awesome (íconos, vía CDN)

El sitio es estático y no usa JavaScript propio. Los proyectos en React y Node.js que se muestran viven en sus propios repositorios, enlazados desde cada tarjeta.

## Cómo verlo en tu computadora

1. Cloná el repositorio:
   ```
   git clone https://github.com/caro4576/caro-bibbo-portfolio.git
   ```
2. Abrí `index.html` en el navegador, o usá la extensión Live Server de VS Code.

## Deploy

El sitio está publicado en Vercel y se actualiza automáticamente con cada `push` a la rama `main`.
